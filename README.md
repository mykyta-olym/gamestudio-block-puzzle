## Introduction

**Project Overview**

Welcome to **Block Puzzle Game** - a modern twist on a classic puzzle game experience designed to challenge your spatial reasoning and problem-solving skills. This digital rendition of timeless block-fitting puzzles offers fun and engaging gameplay with layers of complexity through various modes.

**Purpose and Problem Solving**

The game aims to:
- Alleviate boredom with accessible entertainment.
- Enhance cognitive skills like spatial awareness and planning.
- Provide stress relief through a fun, engaging medium.

**Innovation and Technology**

Built with Java, the game features a console-based UI, providing clear feedback and intuitive controls. Its modular design allows easy expansion, catering to puzzle enthusiasts and developers alike.

## Features

- **Hints**: In-game hints to assist players.
- **Comments**: Player commentary system for interactive feedback.
- **Login/Register**: User authentication for personalized experiences.

## Quick Start

**Running the Game**

Ensure Java (version 8+) is installed. Clone the repository and build the project using Gradle. Run the game with:


git clone your-repository-url.git
cd block-puzzle-game
./gradlew build
java -jar build/libs/block-puzzle-game.jar

Gameplay Instructions

Select a mode (Classic or Endless) and use strategic moves to clear lines. The game offers intuitive controls detailed within.
